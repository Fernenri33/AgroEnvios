# 🌱 AgroEnvíos

AgroEnvíos es una plataforma web con una API en Spring Boot y un frontend en Svelte/Vite, diseñada para facilitar servicios de logística y gestión en el sector agroindustrial.

## 📦 Estructura del Proyecto

## 🚀 Tecnologías

### Backend (API)

- Java (Spring Boot)
- Maven
- Perfil de producción: `--spring.profiles.active=prod`

### Frontend

- Svelte
- Vite
- Despliegue con `pm2`

## 🔧 Despliegue en Servidor (DigitalOcean)

### Prerrequisitos

- Git instalado
- Java 17+ y Maven
- Node.js y npm
- `pm2` instalado globalmente: `npm install -g pm2`
